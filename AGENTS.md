# NOVOOI Romplanlegger

For every user-facing update, update the dated release note in the in-app version history in `openSettings()` in `public/planner.html`. Describe the change in plain Norwegian. Keep the release number consistent with `package.json` and `package-lock.json`.

Use one release-note entry per calendar day in Europe/Oslo. Merge any later changes that day into the same entry and set its version to the latest release.
